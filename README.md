# 🎭 Creative Hello World Collection

面白い方法でHello Worldを表示するPythonスクリプトです！

## 🌟 Features

8種類の異なるエフェクトでHello Worldを表示：

1. **🌊 Wave Effect** - 波のように揺れるHello World
2. **💚 Matrix Style** - マトリックス風に文字が降ってくる
3. **🌈 Rainbow Effect** - 虹色に輝くHello World
4. **⌨️ Typing Effect** - タイピング風に1文字ずつ表示
5. **💥 Explosion Effect** - 爆発するように広がるHello World
6. **📺 Glitch Effect** - グリッチエフェクト
7. **🎨 ASCII Art** - アスキーアートで表示
8. **🔄 Rotation Effect** - 回転するHello World

## 🚀 Usage

```bash
python3 creative_hello_world.py
```

または：

```bash
./creative_hello_world.py
```

## 📋 Requirements

- Python 3.x
- ターミナル環境

## 🎮 How to Use

プログラムを実行すると、メニューが表示されます：
- 1-8: 各エフェクトを個別に実行
- 9: 全てのエフェクトを順番に実行
- 0: 終了

## 🎨 Example

```
選択してください:
1. 🌊 Wave Effect (波エフェクト)
2. 💚 Matrix Style (マトリックス風)
3. 🌈 Rainbow Effect (虹色)
4. ⌨️  Typing Effect (タイピング風)
5. 💥 Explosion Effect (爆発エフェクト)
6. 📺 Glitch Effect (グリッチ)
7. 🎨 ASCII Art (アスキーアート)
8. 🔄 Rotation Effect (回転)
9. 🎪 All Effects (全部見る!)
0. Exit (終了)

選択 (0-9):
```

## 💡 Tips

- 各エフェクトはアニメーション付きです
- ターミナルのサイズを十分に確保してください
- カラーエフェクトはANSIカラー対応ターミナルで最適に動作します
